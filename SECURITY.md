# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub private vulnerability
reporting: open the repository's "Security" tab and choose "Report a
vulnerability". Do not open a public issue or pull request for a suspected
vulnerability.

Include the affected version or commit, steps to reproduce, and the impact you
see. Reports without secrets or personal data are easiest to handle; if a
reproduction needs a credential, say so and do not send the credential.

## What to expect

- Acknowledgement within 7 days.
- A fix or a mitigation plan within 90 days of the report. Coordinated
  disclosure: please keep the issue private for that 90-day window, or until a
  fix is released, whichever comes first.
- Credit in the release notes if you want it.

## Scope and limits

- Capsule Corp is a pre-alpha, single-maintainer project. Only the latest tagged
  release and `main` receive fixes.
- There is no bug bounty. Reports are welcome and appreciated, and carry no payment.
