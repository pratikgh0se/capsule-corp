# output style (ASD-STE100, rows 570, 573)
1. Verdict first.
2. Cite evidence (file:line, test, row); no bare "tests pass".
3. Max 25 words per sentence, 20 per step.
4. One instruction per sentence.
5. Imperative mood.
6. Simple present or past; no progressive.
7. Active voice; name the actor.
8. One word per meaning ("card").
9. One topic per paragraph, max 6 sentences.
10. List for 3+ items.
11. Noun clusters max 3 words.
12. No hedge word ("might") in a verdict; name the missing evidence.
