## What keeps this from going stale (R11 gaps)

`maintenance/notice_gen.py --scan` now also compares compose image lines, workflow `uses:` lines, release-URL downloads, pinned `pip install` lines in workflows, Brewfile, bootstrap.lock and every `declared.json` key against `NOTICE.md`, and Dockerfile pins against the committed pip-licenses JSON; `--check` fails on a file with a "lifted from <owner>/<repo>" header, or anything under `capsule/licenses/`, that NOTICE does not name, and on a newest SCAN document older than 90 days. `declared.json` accepts the class `source-available`.

Note: web-layer.pip-licenses.json is not regenerated in this pass (it needs the image). The python-layer JSON covers the web stack's python pins.
